# Human CDL Instructor Validation Checklist

- [ ] Steering ratio feels correct
- [ ] Tractor turning radius resembles training truck
- [ ] Trailer response resembles a real 53 ft trailer
- [ ] Trailer response is not artificially fast
- [ ] Mirror perspective feels natural
- [ ] Blind spots are represented correctly
- [ ] Straight-line backing geometry is correct
- [ ] Offset backing geometry is correct
- [ ] Alley dock geometry is correct
- [ ] Pull-up detection is correct
- [ ] Boundary detection is correct
- [ ] Final positioning requirement is reasonable
- [ ] Mistakes possible in a real truck are possible in simulator
- [ ] Simulator does not secretly help the driver
- [ ] Successful simulator techniques transfer to the real vehicle
