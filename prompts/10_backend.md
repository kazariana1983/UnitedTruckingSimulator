# Prompt 10 - Backend Engineer

Build backend using Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, and Docker.

Entities:
School, Instructor, Student, SimulatorStation, VehicleConfiguration, TrailerConfiguration, Exercise, Attempt, TelemetrySession, Score, ScoreEvent, InstructorNote.

Implement authentication, role-based authorization, CRUD APIs, attempt creation, telemetry upload, attempt completion, score retrieval, student history, instructor notes, and simulator station heartbeat/status.

Roles: Admin, Instructor, Student, SimulatorStation.

Requirements:
- OpenAPI docs
- migrations
- validation
- structured logging
- tests
- health endpoint
- environment-based config
- secure password handling
- no secrets in source
- local Docker development environment

Build module-by-module and run tests after each module. Do not implement AI coaching yet.
