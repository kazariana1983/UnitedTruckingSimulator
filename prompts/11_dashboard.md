# Prompt 11 - Instructor Dashboard Engineer

Build a React + TypeScript instructor dashboard using the existing backend APIs.

Screens:
- Login
- Dashboard: active simulator stations, current students/exercises, attempt duration, live status
- Students: list/detail/history
- Attempts: exercise/date/score/duration/penalties/notes
- Attempt Detail: score, pass/fail, timeline, mistakes, telemetry summary, notes
- Reports: improvement, average scores, attempts/exercise, frequent mistakes

Priorities:
1. simple
2. readable for nontechnical instructors
3. desktop/tablet friendly
4. minimal animation
5. critical information visible immediately

Do not create fake backend logic in the frontend.
Include loading, empty, error, API failure, and authorization states.
